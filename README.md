# Portofolio Dede Maulana (React + Vite)

## Menjalankan
1. Pasang Node.js 18 atau lebih baru.
2. `npm install`
3. `npm run dev`  → buka alamat yang muncul (biasanya http://localhost:5173)
4. `npm run build` → hasil siap deploy ada di folder `dist/`

## Struktur
- `src/App.jsx`   : seluruh komponen dan data (teks proyek, sertifikat, timeline)
- `src/styles.css`: gaya, Light/Dark Mode, dan gradasi (bagian "GRADASI" di akhir file)
- `standalone/index.html`: versi satu file, bisa dibuka langsung di browser (butuh internet)

## Yang perlu Anda ganti
Foto, thumbnail proyek, gambar sertifikat, email, nomor telepon, tautan sosial, dan file CV.
